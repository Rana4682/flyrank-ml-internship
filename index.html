Refresh / Content Opportunity Scoring

Author: Rana Muhammad Hasnain

Built on the FlyRank ML Internship Dataset

Abstract

This project develops a machine learning approach for identifying content pages that may benefit from refresh activities. Historical search performance signals including CTR, Average Position and Trend Percentage were analyzed. A transparent baseline scoring rule was created and compared against a Random Forest model. The results indicate that the model closely approximates the baseline scoring strategy while providing feature importance for editorial decision support. The findings are observational and intended only to support content prioritization rather than causal conclusions.

1. Research Question

Can historical search performance signals identify content pages that should be refreshed?

  • Unit of Analysis: One content page
  • Output: Ranked Refresh Priority Score
  • Decision: Help editors prioritize content updates

2. Dataset

  • Dataset: FlyRank Internship Warehouse
  • File: content_refresh_anonymized.csv
  • Records: 30,000
  • Columns: 44
  • No client-identifying information used

3. Methodology

A transparent baseline scoring rule was created using three observed search performance signals. The baseline score was calculated from:

  • CTR
  • Average Position
  • Trend Percentage

A Random Forest Regressor was then trained to learn the same scoring behavior. The model used the following features:

  • CTR
  • Average Position
  • Trend Percentage

The target variable was the baseline refresh score. An 80/20 train-test split was used. Missing values were handled before training. Identifier fields such as content_id and client_id were excluded.

5. Limitations

  • Uses anonymized historical data only.
  • Cannot prove causal relationships.
  • External ranking factors are not included.
  • Recommendations are intended for decision-support only.

6. Ranked Recommendations

  • Refresh pages showing declining search trends.
  • Improve pages with low CTR.
  • Review pages with poor average positions.
  • Monitor stable pages before making major updates.

Confidence: Medium

These recommendations are based on observed historical search performance and are intended for decision-support only.
